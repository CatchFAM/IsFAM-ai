# IsFAM AI 최종 정리

작성일: 2026-09-22  
범위: anti-spoofing 모델, 임계값, 통합 추론 경로, 재현 가능한 평가 도구

## 결론

기본 딥보이스 판별기를 378 MB 규모의 wav2vec2 모델에서 26 KB 규모의 로컬 spectral MLP로 교체했다. 같은 DFADD 고정 테스트 800개에서 정확도는 `50.88% → 98.88%`, 가짜 음성 재현율은 `1.75% → 99.50%`로 상승했다. 평균 순수 추론은 `117.18 ms → 2.08 ms`, 통합 가족 확인 파이프라인은 `502.48 ms → 77.48 ms`로 줄었다.

단, 이는 제한된 공개 데이터에서 얻은 1차 결과이며 실제 한국어 전화망 성능 보증값은 아니다. 새 모델은 애매한 점수를 자동 통과시키지 않고 사용자 추가 확인으로 넘기도록 연결했다.

## 현재 AI 구성

```text
통화 음성
  ├─ 온디바이스 가족 화자 인증
  │    ECAPA-TDNN INT8 ONNX → 등록 가족 목소리와 비교
  ├─ 서버 딥보이스 탐지
  │    spectral MLP → AI 합성 음성 점수 계산
  └─ 위험도 판단
       두 결과가 확실하면 안전/위험, 조금이라도 애매하면 사용자 추가 확인
```

| 역할 | 변경 전 | 현재 | 실행 위치 |
|---|---|---|---|
| 가족 화자 인증 | `speechbrain/spkrec-ecapa-voxceleb` | 동일 모델의 ECAPA-TDNN INT8 ONNX | Android 온디바이스 |
| 딥보이스 탐지 | `Vansh180/deepfake-audio-wav2vec2` | `isfam/spectral-mlp-dfadd-v1` | FastAPI 서버 |
| 최종 판단 | 가족 중심 규칙형 점수 | 애매 구간 추가 확인 정책 강화 | 서버/통화 세션 |

이번에 교체한 것은 **딥보이스 탐지 모델**이다. 온디바이스 ONNX는 가족 목소리를 확인하는 별도 모델이며 이번 교체 대상이 아니다. 새 딥보이스 모델도 ONNX가 아니라 NumPy로 실행되는 26 KB MLP다.

## 왜 성능이 크게 올랐나

기존 모델은 범용 대형 모델이지만 현재 XTTS2와 DFADD 생성 음성을 대부분 실제 음성으로 판단했다. 새 모델은 공개 real/fake 음성에서 다음과 같은 합성 음성 흔적에 집중하도록 직접 학습했다.

- 주파수가 지나치게 매끄러운 현상
- 실제 사람과 다른 고주파 패턴
- 음색과 에너지 변화가 부자연스러운 현상
- 짧은 구간의 변화가 지나치게 일정한 현상

음성 전체를 큰 Transformer로 처리하는 대신 이 흔적을 196개 숫자로 압축하고 작은 MLP가 판별한다. 여기에 real 오탐 상한을 고려해 임계값을 다시 정했다. 즉, `현재 데이터와 맞지 않던 범용 모델 → 현재 공격 유형에 맞춘 소형 전용 모델`로 변경한 것이 정확도와 속도가 함께 오른 주된 이유다.

다만 새 모델이 모든 환경에서 본질적으로 더 우수하다는 뜻은 아니다. 학습과 평가가 같은 5개 생성기 계열에 속해 있어 생성기 특유의 흔적을 배웠을 가능성이 크다.

## 동일 테스트셋 비교

평가 데이터는 [DFADD 공개 데이터](https://huggingface.co/datasets/SpeechAntiSpoofingBenchmarks/DFADD)에서 원본 발화가 calibration/test 양쪽에 겹치지 않도록 고정 추출했다. Test는 real 400개와 fake 400개이며, fake는 Grad-TTS, Matcha-TTS, NaturalSpeech2, PFlow-TTS, StyleTTS2를 각 80개씩 포함한다.

| 지표 | 기존 wav2vec2 | 새 spectral MLP | 변화 |
|---|---:|---:|---:|
| 정확도 | 50.88% (407/800) | 98.88% (791/800) | **+48.00%p** |
| fake recall | 1.75% (7/400) | 99.50% (398/400) | **+97.75%p** |
| fake 누락 | 393개 | 2개 | **99.49% 감소** |
| real 오탐률 | 0.00% (0/400) | 1.75% (7/400) | **+1.75%p** |
| precision | 100.00% | 98.27% | -1.73%p |
| 평균 순수 추론 | 117.18 ms | 2.08 ms | **56.4배 빠름** |
| p95 순수 추론 | 284.90 ms | 2.65 ms | **107.7배 빠름** |
| 평균 변환 포함 | 149.68 ms | 32.85 ms | **4.56배 빠름** |
| 처리량 | 6.68 files/s | 30.34 files/s | **4.54배 증가** |

운영 임계값은 calibration 400개(real 200/fake 200)에서 정한 `0.5107068233`이다. Calibration에서는 400/400을 맞혔지만 이 값은 학습에 사용된 소규모 데이터 결과이므로 일반화 수치로 사용하지 않는다.

## 기존 보유 XTTS2 재검증

| 항목 | 기존 기본 모델 | 새 기본 모델 | 변화 |
|---|---:|---:|---:|
| XTTS2 fake 탐지 | 23/2,000 (1.15%) | 1,873/2,000 (93.65%) | **+92.50%p, 81.4배** |

XTTS2 세트는 fake-only이므로 이 표는 fake recall만 뜻한다. 정확도·precision·real 오탐률은 계산할 수 없다. 별도로 보유한 가족 실제 음성 10개에서는 새 모델 오탐이 0개였지만 표본이 너무 작아 일반화할 수 없다.

## 전체 통합 판단 속도

같은 가족 실제 음성 10개를 파일당 3회, 워밍업 후 측정했다. 파일 평균 길이는 10.81초이며 모델과 위험도 계산 시간만 포함한다.

| 지표 | 기존 | 새 기본값 | 변화 |
|---|---:|---:|---:|
| 통합 평균 | 502.48 ms | 77.48 ms | **6.49배 빠름, 84.58% 감소** |
| 통합 p95 | 614.47 ms | 103.80 ms | **5.92배 빠름** |
| 가족 화자 인증 평균 | 73.27 ms | 75.32 ms | 거의 동일 |
| anti-spoof 평균 | 429.20 ms | 2.14 ms | **200.6배 빠름, 99.50% 감소** |

사용자 체감 시간에는 3~5초 음성 수집, 업로드, 오디오 변환 시간이 별도로 더해진다. 이번 개선은 그중 서버 판단 병목을 제거한 것이다.
기존 모델은 긴 파일을 중첩 window로 훑었고 새 기본 모델은 중앙 5초를 분석하므로, 이 통합 속도 비교는 현재 API의 3~5초 chunk 운용 계약을 전제로 한다.

## 실제 전화환경 판단

현재 보유 데이터와 3~5초 통화 chunk 구조에서는 새 모델이 기존 모델보다 적합하다. 더 빠르고, 현재 시험한 생성 음성을 훨씬 많이 잡으며, 서버 부하도 작다. 따라서 현재 기본 모델로 사용하는 결정은 타당하다.

하지만 아래 조건을 아직 직접 시험하지 않았으므로 실제 전화환경에서도 정확도가 `98.88%`라고 단정할 수는 없다.

- 전화망 codec과 음질 저하
- 주변 잡음, 끊김, 잔향
- 스피커로 AI 음성을 재생한 뒤 다시 녹음하는 공격
- 한국어 실제 통화
- 학습에 없던 새로운 생성기

추가 원본 데이터를 구하지 못하더라도 현재 real/fake 음성에 전화 codec, 잡음, 거리, 재생 효과를 인위적으로 적용해 강건성 평가를 확장할 수 있다. 그 검증 전까지는 새 모델을 기본으로 사용하되 애매한 결과를 사용자 확인으로 넘기는 현재 정책을 유지한다.

## 배포 및 안전 정책 변경

- 기본 backend를 `spectral`로 변경하고 기존 Transformers 모델은 `ISFAM_ANTI_SPOOFING_BACKEND=transformers`로 되돌릴 수 있게 유지했다.
- 모델 파일은 `26,309 bytes`, 기존 가중치 `378,302,360 bytes` 대비 **14,379배 작고 99.993% 감소**했다.
- 통합 API의 오디오 변환·음질 검사·모델 실행을 threadpool로 옮겨 async 이벤트 루프 정체를 줄였다.
- spoof 점수 `0.357495 이상 0.510707 미만`은 애매 구간으로 보고, 가족 음성과 비슷해도 `caution / family_voice_needs_confirmation`으로 사용자 재확인을 요구한다.
- 낮은 음질, 가족 유사도 기준 근처, 등록되지 않은 화자는 기존과 같이 자동 신뢰하지 않는다.


공개 음원과 원시 CSV/JSON 결과는 용량과 라이선스 관리를 위해 git에서 제외했다. 고정 모델 artifact의 SHA-256은 `9c368012f9919acb19cd32d9eeb2e1db52301654869eee9d73a22b0261034ead`이다.

## 남은 한계

- DFADD 평가가 2명 화자와 학습 때 본 5개 생성기 계열에 한정돼 있다.
- 한국어, 전화 codec, 잡음, 스피커 재생 후 재녹음, 미지 생성기 성능은 아직 측정하지 못했다.
- spectral 모델은 API 권장 입력인 3~5초 chunk용이다. 긴 파일은 현재 중앙 5초만 본다.
- real 오탐이 0%에서 1.75%로 증가한 대가가 있다. 제품에서는 이를 즉시 위험 확정이 아니라 추가 확인 흐름으로 완화한다.
- 따라서 `98.88%`는 현재 고정 벤치마크 성능이며 실제 서비스 정확도로 홍보하면 안 된다.
